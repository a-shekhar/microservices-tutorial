# Microservices learning projects

- [Microservices basics](01-microservices-basics/README.md): limits service and Config Server.
- [Currency system](02-currency-exchange/README.md): exchange, conversion, discovery and gateway.
- [Docker](03-docker/README.md) and [Kubernetes](04-kubernetes/README.md) practice and interview topics.
- [Properties and annotations](../PROPERTIES-AND-ANNOTATIONS.md).

Install JDK 25. Run each application in its own terminal using its Maven wrapper: on Windows run `.\mvnw.cmd spring-boot:run` from its folder; on macOS or Linux run `./mvnw spring-boot:run`. Follow the linked guides for startup order.
