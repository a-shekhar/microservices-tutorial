# Properties and annotations explained

This guide describes the settings and Java annotations in this workspace. A property is a name and value used to configure an application. An annotation starts with `@` and tells Java or a library how to treat code. Lines beginning with `#` in a properties file and `//` in Java are comments; they do not turn features on.

## Application properties

| Property | Meaning in this project |
| --- | --- |
| `spring.application.name` | Gives the application its name. Config Server uses it to find matching configuration; Eureka uses it as the service name. |
| `server.port` | Port on which the application listens. A command-line or environment override can select another port. |
| `local.server.port` | Actual port of a running embedded server, read by controllers to show which instance answered. It is not a setting in the files. |
| `spring.config.import` | Imports configuration from Config Server. `optional:configserver:...` allows startup when it cannot be reached; without `optional:` the limits service requires it. Imported values and other sources follow Spring's property precedence. |
| `spring.profiles.active` | Selects a profile such as `dev`. Profile-specific files can supply different values. The commented `native` example selects Config Server's filesystem backend. |
| `limits-service.minimum`, `limits-service.maximum` | Custom integer values bound to `LimitsConfiguration`. Default, dev and qa files provide different examples. |
| `spring.cloud.config.server.git.uri` | Location of the Git repository used by Config Server. The checked-in path points to an old location; override it for your machine. Git serves committed configuration. |
| `spring.cloud.config.server.native.search-locations` | Commented example of a folder for the native backend. It has no effect until enabled with the native profile and a suitable path. |
| `spring.jpa.show-sql` | Prints SQL generated by JPA to the application output. |
| `spring.datasource.url` | Database connection address; `jdbc:h2:mem:testdb` selects an in-memory H2 database. |
| `spring.datasource.username`, `spring.datasource.password` | Credentials for that database. These sample values are for local learning. |
| `spring.h2.console.enabled` | Enables the H2 web console. |
| `spring.jpa.defer-datasource-initialization` | Delays SQL data initialization until after JPA creates the schema, so `data.sql` can insert rows. |
| `eureka.client.serviceUrl.defaultZone` | Address of the Eureka server used by clients to register and find services. |
| `eureka.instance.hostname` | Address advertised to Eureka clients. In `03-docker`, exchange and conversion default to `${EUREKA_INSTANCE_HOSTNAME:localhost}`; override with a reachable hostname for separate hosts or containers. |
| `eureka.client.fetch-registry` | When false, the Eureka client does not fetch the registry. |
| `eureka.client.jersey.enabled` | Controls the Jersey-based Eureka client transport; the server configuration sets it to false. Transport availability depends on dependencies. |
| `eureka.client.register-with-eureka` | When false, the standalone naming server does not register itself as a Eureka client. |
| `resilience4j.retry.instances.sample-api.maxAttempts` | Maximum attempts for the named retry, including the first call. |
| `resilience4j.retry.instances.sample-api.waitDuration` | Initial wait between retries: one second here. |
| `resilience4j.retry.instances.sample-api.enableExponentialBackoff` | When enabled, retry waits grow between attempts. The retry annotation is currently commented out. |
| `resilience4j.ratelimiter.instances.default.limitForPeriod` | Permits two calls in each refresh period for the named limiter. |
| `resilience4j.ratelimiter.instances.default.limitRefreshPeriod` | Refreshes those permits every ten seconds. The rate limiter annotation is currently commented out. |
| `resilience4j.bulkhead.instances.default.maxConcurrentCalls` | Allows at most ten simultaneous calls through the named bulkhead. |
| `spring.cloud.gateway.discovery.locator.enabled` | Commented legacy-style example for discovery-generated gateway routes; version support varies. |
| `spring.cloud.gateway.server.webflux.discovery.locator.enabled` | Commented WebFlux setting that enables routes generated from discovered services. |
| `spring.cloud.gateway.server.webflux.discovery.locator.lower-case-service-id` | Commented setting to use lowercase service IDs in generated route paths. Neither commented gateway setting is active. |
| `management.tracing.sampling.probability` | Fraction of eligible traces to sample. The `03-docker` business services use `1.0` for local learning; sampling alone does not configure propagation or a Zipkin exporter. |
| `logging.pattern.level` | In `03-docker`, includes the application name plus trace and span IDs when available, so logs can be correlated. It does not send spans to Zipkin. |

A profile filename such as `limits-service-dev.properties` combines the application name and profile. The client can also have local values. Higher-priority property sources can override lower-priority ones.

## Java annotations

| Annotation | Meaning and example |
| --- | --- |
| `@SpringBootApplication` | Marks the main application and enables Boot configuration and component scanning. `SpringApplication.run` starts it. |
| `@EnableConfigServer` | Turns the application into a Spring Cloud Config Server. |
| `@EnableEurekaServer` | Enables the Eureka registry server. |
| `@EnableFeignClients` | Finds Feign interfaces and creates clients for them. |
| `@FeignClient(name = "currency-exchange")` | Creates an HTTP client for the named service. Without a fixed URL, discovery/load balancing can select an instance. The fixed URL example is commented out. |
| `@Configuration` | Marks a class that provides Spring configuration. |
| `@Configuration(proxyBeanMethods = false)` | Disables interception of calls between bean methods. Inject bean dependencies as parameters; a direct method call is an ordinary Java call and may create another object. |
| `@ConfigurationProperties(prefix = "limits-service")` | Binds matching properties such as `limits-service.minimum` to fields on the class. |
| `@Bean` | Makes the object returned by a method available to Spring; the gateway uses it for routes. |
| `@Component` | Registers a class as a Spring-managed object; used for the gateway filter. |
| `@Repository` | Marks a data access component. Spring Data implements the repository interface and derives its lookup from the method name. |
| `@RestController` | Marks a web controller whose return values are written to the HTTP response, normally as JSON for objects. |
| `@GetMapping` | Maps an HTTP GET request to a method or Feign operation. |
| `@PathVariable` | Takes a value from a URL placeholder, such as `{from}`, and passes it to a method parameter. |
| `@Autowired` | Asks Spring to supply a dependency, such as a repository, environment or client. It appears on fields and constructors. |
| `@Entity` | Maps a class to a database table through JPA. |
| `@Id` | Marks the entity's primary key. |
| `@GeneratedValue(strategy = GenerationType.IDENTITY)` | Lets the database generate the ID using an identity column. |
| `@Column(name = ...)` | Connects a Java field to a named database column. |
| `@Data` | Lombok generates common methods including getters, setters, `equals`, `hashCode` and `toString`. |
| `@NoArgsConstructor`, `@AllArgsConstructor` | Lombok generates a constructor with no arguments or with one argument for each field, respectively. |
| `@CircuitBreaker(name = "default", fallbackMethod = "errorResponse")` | Tracks failures and can stop calls temporarily; the named fallback handles applicable failures. The fallback must have a compatible signature. |
| `@Bulkhead(name = "default")` | Limits concurrent work so too many calls do not occupy the service at once. |
| `@Retry` | Can repeat failed calls using named retry settings. The example is commented out. |
| `@RateLimiter` | Can restrict how often calls are allowed. The example is commented out. |
| `@Override` | Java checks that a method implements or overrides a method from a parent type. |
| `@SpringBootTest` | Starts a Spring application context for a test. |
| `@Test` | Marks a JUnit test method. |

## Maven and wrapper properties

Each `pom.xml` sets `java.version` to 25 and `spring-cloud.version` to 2025.1.4. The parent and dependency management provide versions for many dependencies. `${spring-cloud.version}` refers to the property. Wrapper files set `wrapperVersion`, `distributionType` and `distributionUrl` to select how the wrapper obtains Maven; these are build-tool settings, not application settings. Individual modules may specify different Maven distribution URLs.

For the `03-docker` POM dependencies, their tracing roles, the `RestTemplateBuilder` bean, and all example URLs, see the [project reference](01-in28minutes/03-docker/PROJECT-REFERENCE.md) and [tracing interview questions](INTERVIEW-GUIDE.md#10-distributed-tracing-in-the-03-docker-example).
